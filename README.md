Project Description

My project is a web page designed to be my portfolio created for my INFR3120 Web and Script Programming assignment at Ontario Tech University.
The website was developed using HTML5 and CSS3. It contains a navigation bar that allows the user to switch between the home page, about me page, projects page and contact page. The home page acts as a brief introduction to the portfolio. The about me contains information about myself, an image of me, and a video explaining a bit about myself. The projects page includes 4 of my projects from studying at ontario tech university. While also providing a link to download them and giving a brief explanation about each project. Finally the contacts page was created to provide my email and allow the user to input their email and send a message. I also made 3 different css files to accommedate for laptop, tablet and mobile viewports.

Technologies Used

The technology used includes, HTML5 for website structure and content, CSS3 for styling and responsive layouts, Visual Studio Code for development, Git and GitHub for version control and GitHub Pages for website hosting.

Responsive Web Design

The website was built using three css files, laptop.css, tablet.css, and mobile.css. Laptop.css being for laptop dimensions, tablet.css being for tablet dimensions, and mobile.css being for mobile dimensions. CSS media queries are used to adjust the layout and formatting depending on the webpage size. The viewport sizes are 480px and below for mobile, 481px to 960px for tablet and 961px and above for laptop.


Colour Scheme and Design
For my portfolio, I decided to use a dark blue background with white text and lighter blue colours for headings and links. I wanted to keep the colours similar throughout all four pages. For the mobile version, I made the navigation links into brighter blue buttons so they stand out more on smaller screens.

Gradients

I used two gradients in my laptop CSS file. The navigation bar has a gradient that goes from dark blue to a brighter blue from left to right.

I also added a diagonal gradient to the footer using two different shades of dark blue. I used these gradients to make the website look less plain while keeping the same blue colour scheme.


Website Testing and Validation

I tested my website using different online tools to make sure everything was working properly. I used the HTML and CSS validators to check my code for errors, WAVE to check for accessibility issues, and the W3C Link Checker to make sure my links were working. I also checked my website over for spelling mistakes.
